# 하트트랙

물 섭취·운동 기록 웹앱 (아이폰 홈 화면 앱 지원)

| 탭 | 기능 |
|---|---|
| 대시보드 | 오늘의 물 섭취·러닝·근력·운동 시간 요약, 빠른 기록 |
| 물 섭취 | 물 섭취 기록, 목표 진행률, 빠른 추가 (1모금·한 잔 등) |
| 러닝 | 러닝 거리 기록, 목표 설정, 빠른 추가 |
| 근력 운동 | 세트·볼륨 기록, 부위별 운동 |
| 운동 시간 | 운동·휴식 시간 기록, 타이머 |
| 내역 및 분석 | 기록 목록, 차트·통계 |

- 기록은 이 기기(localStorage)에만 저장됩니다. 서버로 보내지 않아요.
- Chart.js로 그래프 표시, 다크/라이트 테마 지원
- 아이폰 홈 화면 앱으로 사용 가능
